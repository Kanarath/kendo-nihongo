# Kendō Nihongo

App web (PWA) para aprender japonés sin vidas, sin energía y sin rachas, con Chopper como mascota.
Hiragana, katakana, kanji N5, gramática básica, lecturas y examen de nivel. Funciona sin conexión.

Es un sitio estático: no hay build. Se publica con GitHub Pages desde la rama `main`.
